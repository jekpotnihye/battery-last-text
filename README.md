# The Battery's Last Text to Its Charger

One line of plain text: the phone battery's last text message to the
charger it waited for all day. The program writes the text to
`/output/entry.txt`.

Entry:

> I waited all day on 1% for you. You charged your ex's phone.

Run it with:

```sh
python3 main.py
```
